Clan bot guide

KNYWBot

Chats, banters, drops the occasional GIF, and keeps the server tidy. Here's everything it can do.

Chatting GIF reactions Reaction roles Server rules Mod commands

💬Talking to it

@mention it, anywhere it's active

Tag @KNYWBot with your question or your nonsense and it'll reply — casual, clan-voice, not a customer-service bot. It knows Diablo 4 in general terms but has no live game data, so for anything current-season/meta-specific it'll say so instead of guessing.

It remembers the conversation — briefly

Follow-up messages within the same back-and-forth keep context. Go quiet for an hour and it starts fresh next time you mention it.

🎬GIF reactions

It jumps into chat on its own — sometimes

No command needed. When something in chat is genuinely funny, hype, or a disaster, it might reply with a fitting GIF. It's deliberately picky — most messages don't get one, so it doesn't turn into noise.

🎭Reaction roles

React to opt in, unreact to opt out

Where set up, reacting with a specific emoji on a pinned message grants you the matching role instantly — no command needed. Removing your reaction removes the role. Ask a MODZ member which messages have this set up on your server.

🛡️Keeping the server clean

These happen automatically, for everyone except MODZ — if your message vanishes, it's probably one of these:

  • Discord invite links get removed on sight.
  • Mass-mentioning a bunch of users/roles in one message gets removed.
  • Posting too fast (spam bursts) gets caught and cleaned up.
  • Banned words, if the server has any configured, get removed too.
Not a punishment log you can see — actions like these are recorded in a private mod-log channel for MODZ, not posted publicly.

🔧Mod commands

Only usable by members with the MODZ role.

/kick

Remove a member from the server.

/ban

Ban a member from the server.

/mute

Time out a member for a set number of minutes.

/purge

Bulk-delete recent messages in a channel.

/reactionrole-add

Wire up a new reaction role: point it at a message, an emoji, and a role — it reacts to the message and registers the mapping in one step.
