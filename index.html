👁️What it reads, and where

The short version: every message is checked for auto-mod rules. Only two channels feed a message's actual content to an AI model, and only two features do that.

FeatureWhere it runsWhat it does with the text
Auto-mod scanEvery channel, every messagePattern-checked locally (invite links, mention count, banned words, posting speed) — never sent to an AI model
AI chat#knywbot-testing, #💀-town-square — only when @mentionedSent to an AI model to generate a reply
GIF reactions#knywbot-testing, #💀-town-square — every message, not just mentionsOccasionally sent to an AI model to judge if it's reaction-worthy
Not monitored: DMs (the bot doesn't read or respond to direct messages), voice channels/voice chat, and — for chat/GIF purposes — every channel outside the two listed above. Auto-mod's pattern checks (invites/mentions/spam/banned words) are the exception: those run server-wide, in every text channel, since that's a moderation function rather than a conversational one.
Members with the MODZ role are exempt from auto-mod entirely — their messages aren't pattern-checked.

Feature

💬Chatting with the bot

@mention it in an active channel

Tag @KNYWBot with your question or your nonsense in #knywbot-testing or #💀-town-square and it replies — casual, clan-voice, not a customer-service bot. Mentioning it anywhere else does nothing.

It has no live game data

It's a general-purpose AI model with a Diablo 4-flavored personality prompt, not a build database. For current-season/meta-specific questions it's told to admit it doesn't know rather than invent a plausible-sounding but wrong answer — including build names, item names, or links. If it ever states something oddly specific and confident about current patch content, be skeptical.

It remembers your conversation — briefly

Follow-ups keep context for up to the last 10 messages between you and it. Go quiet for 60 min and it forgets — next mention starts fresh. This memory lives only in the bot's running memory (RAM); a bot restart clears everyone's context instantly, and it's never written to disk.

Anti-flood limits

Per person: 1 msg / 12s cooldown, and 50 messages/day. Server-wide: at most 3 replies being generated at once — if you're rate-limited you'll get a short heads-up instead of silence (except when the server-wide limit is the cause, which stays silent to avoid adding more noise while already busy).

Steered away from a few topics

It's instructed to decline or steer off real-money-trading/gold-selling/account-selling talk and cheat/exploit/botting discussion. Standard AI safety filtering (harassment, hate speech, explicit content) applies underneath regardless.

Feature

🎬GIF reactions

It's watching for a good moment — not every message

In the same two channels as chat, every message (not just @mentions) is a candidate. On each one, it rolls a 15% chance to even consider reacting, and won't consider another one within 240s of its last GIF — so it can react at most once every 4 minutes, and usually less often than that.

When it does consider one, an AI model judges the vibe

It's instructed to be picky — funny, hype, a brag, a fail, a rage-quit moment — and to skip anything ordinary. If it decides something fits, it picks a short search phrase and posts a matching GIF as a reply to that message. The match is vibe-based, not a literal keyword echo, so it can occasionally read a message differently than you'd expect.

Feature

🛡️Auto-mod

Runs on every message, in every text channel on the server — this is the one feature not limited to the two AI channels. Checked in order; the first match wins and the message is deleted immediately.

  • Discord invite link posted any discord.gg/… or discord.com/invite/… link, always on
  • Mass-mentioning >5 users/roles in one message counts users and roles together
  • A banned word/phrase currently no words configured — this rule is a no-op until a mod adds some
  • Posting too fast: more than 5 messages within 7s tracked per person, server-wide
Every auto-mod deletion is recorded — see Logging below.

🗂️Logging & data retention

Everything below posts to a private #mod-logs channel, visible only to MODZ — none of it is public.

EventWhat's recorded

Message editedAuthor, channel, before & after text
Auto-mod actionWho, where, which rule, and the offending text

What's NOT stored anywhere long-term: ordinary chat messages that are never edited/deleted, and the 1-hour conversation memory described above (in RAM only, never written to disk). There's no permanent database of everything anyone's said.

🎭Roles

Join role

New members automatically get a Member role the moment they join — nothing to do on your end.

Reaction roles none set up yet

The system exists — react with a specific emoji on a message a mod has wired up, and you instantly get a matching role; remove your reaction to remove the role — but no messages currently have this configured on this server. This section will get more specific once one exists.

🔧Mod commands

Gated by the MODZ role specifically — not Discord's built-in Kick/Ban/etc. permissions. Someone can have full server admin rights and still not be able to run these without the role, and vice versa.

/kick

Remove a member from the server. Takes an optional reason.

/ban

Ban a member from the server. Takes an optional reason.

/mute

Discord-native timeout for a given number of minutes, with a reason.

/purge

Bulk-delete up to 100 recent messages in the current channel.

/reactionrole-add

Point it at a message ID, an emoji, and a role — it reacts to the message with that emoji and registers the mapping in one step, so members can immediately start self-assigning.

Behind the scenes

Every number on this page (cooldowns, thresholds, the mod role name, banned words) is tunable live by the bot owner through a private admin panel, with no bot restart needed. It's not member-accessible — mentioned here purely for completeness, since this page aims to reflect exactly what's actually running, not just what shipped on day one.
